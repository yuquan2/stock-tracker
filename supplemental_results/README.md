# 补充查询结果

本目录保存基于仓库已有 `data/*.csv` 日线快照执行的补充历史查询，
不属于每日定时任务生成的 `results/` 目录。

筛选规则与当前程序一致：

- D1 收盘价高于 D1 开盘价。
- D1 成交量不少于 D0 成交量的 1.9 倍。
- D1 最高价高于 D1 收盘价。
- D2 最高价等于 D1 收盘价。
- D2 最低价等于 D1 开盘价。
- 股票池排除 ST、科创板和北交所股票。

文件说明：

- `a_share_screening_1.9x_2025.csv`：使用本地保存的 2025 年数据计算，
  数据覆盖 2025-08-27 至 2025-12-31，共 21 条结果。
- `a_share_screening_1.9x_2026.csv`：使用本地保存的 2026 年数据计算，
  数据覆盖 2026-01-05 至 2026-10-29，共 30 条结果。

结果仅反映仓库中已保存数据的覆盖范围，不代表对应自然年度的完整历史行情。
